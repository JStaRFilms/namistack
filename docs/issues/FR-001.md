# [FR-001] File Picker + Clip List With Metadata

## Labels
`MUS`, `enhancement`, `ingest`

## User Story
As a user, I want to open media files and see them in a list with basic metadata, so that I can choose inputs.

## Proposed Solution

### Overview
Provide a file picker that accepts one or more files, then display a clip list showing filename, duration, resolution, codec, and size.

### Implementation Flow
1. Renderer triggers “Open Files” action.
2. Preload exposes IPC to open a native file dialog and return selected paths.
3. Main process runs `ffprobe` (or `ffmpeg -i`) to fetch metadata per file.
4. Renderer renders a clip list with metadata and selection controls.

### Technical Approach

```ts
// Main process: metadata lookup
ipcMain.handle('media:open', async () => {
  const { canceled, filePaths } = await dialog.showOpenDialog({
    properties: ['openFile', 'multiSelections'],
    filters: [{ name: 'Media', extensions: ['mp4','mov','mkv','mp3','wav','avi','webm'] }]
  });
  if (canceled) return [];
  return await Promise.all(filePaths.map(getMediaInfo));
});
```

### Key Considerations
- Support drag-and-drop as a secondary input path.
- Cache metadata to avoid repeated probe calls.
- Display unsupported files with a clear error state.
