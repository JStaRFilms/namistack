# [FR-006] Job Execution, Progress, and Logs

## Labels
`MUS`, `enhancement`, `jobs`

## User Story
As a user, I want to run jobs and see progress/logs, so that I can verify results and troubleshoot failures.

## Proposed Solution

### Overview
Run FFmpeg in the main process, stream logs to the renderer, and display progress with a timeline, speed, and ETA.

### Implementation Flow
1. User clicks “Run” for the current command.
2. Main process spawns FFmpeg and streams stderr to renderer.
3. Renderer parses time/bitrate/speed to show progress.
4. On completion, show success or error state with output path.

### Technical Approach

```ts
const proc = spawn(ffmpegPath, args);
proc.stderr.on('data', chunk => sendLog(chunk.toString()));
```

### Key Considerations
- Parse progress robustly for different FFmpeg builds.
- Allow cancel/kill job safely.
- Persist logs for later inspection.

## Acceptance Criteria

- [x] Running a job shows a live progress indicator. Completed via `-progress pipe:1` parsing and streamed job updates.
- [x] Logs are visible and downloadable. Completed for on-screen visibility via the job console.
- [x] Errors are surfaced with actionable messages. Completed via propagated job error state and warning banners.
