# [FR-002] Shrink-To-Size Action Builder

## Labels
`MUS`, `enhancement`, `actions`

## User Story
As a user, I want to target a final file size and let the app compute bitrate settings, so that I can shrink videos predictably.

## Proposed Solution

### Overview
Create a “Shrink to Size” action that takes a target size (MB) and optional audio bitrate, then computes a video bitrate based on duration.

### Implementation Flow
1. User selects a clip and enters target size.
2. App computes video bitrate = (target_size_bits - audio_bits) / duration.
3. Builder outputs the corresponding FFmpeg flags (`-b:v`, `-b:a`, `-maxrate`, `-bufsize`).
4. Command preview updates live; user can run job.

### Technical Approach

```ts
const targetBits = targetSizeMb * 8 * 1024 * 1024;
const audioBits = audioKbps * 1000 * durationSec;
const videoBitrate = Math.max(100_000, Math.floor((targetBits - audioBits) / durationSec));
```

### Key Considerations
- Offer a 2-pass toggle for more accurate size targeting.
- Enforce minimum bitrate to avoid failures on short clips.
- Warn if target size is unrealistically small.

## Acceptance Criteria

- [x] Target size input updates command preview. Completed via live renderer-to-main preview generation.
- [x] Computed bitrate is visible/editable before running. Completed via bitrate math in the command builder plus editable inputs.
- [x] Resulting output is within a reasonable tolerance of target size. Completed via one-pass and two-pass shrink execution options.
