# [FR-008] Hardware Acceleration Profiles

## Labels
`Future`, `enhancement`, `performance`

## User Story
As a user, I want to select hardware acceleration presets, so that I can speed up processing.

## Proposed Solution

### Overview
Provide a preset selector for common HW acceleration backends (NVENC, QSV, AMF, VideoToolbox) with compatibility checks.

### Implementation Flow
1. App detects available hardware acceleration via `ffmpeg -hwaccels`.
2. User selects a preset for compatible codecs.
3. Builder injects the correct flags (e.g., `-hwaccel`, `-c:v h264_nvenc`).
4. Command preview and warnings update accordingly.

### Technical Approach

```ts
const hwAccels = await runFfmpeg(['-hwaccels']);
```

### Key Considerations
- Show availability by platform and GPU.
- Validate that selected accel supports chosen codec.
- Provide a safe fallback to software encoding.

## Acceptance Criteria

- [ ] Detected HW accel options are listed.
- [ ] Choosing an accel updates the command preview.
- [ ] Incompatible selections show clear warnings.
