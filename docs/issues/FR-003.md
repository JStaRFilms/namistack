# [FR-003] Convert Format Action Builder

## Labels
`MUS`, `enhancement`, `actions`

## User Story
As a user, I want to choose an output format and codec options, so that I can convert media reliably.

## Proposed Solution

### Overview
Provide a conversion panel where users select output container, video codec, audio codec, and quality presets (CRF/bitrate).

### Implementation Flow
1. User selects a clip and opens the Convert action.
2. User picks container and codecs; optional quality preset is applied.
3. Builder generates flags (`-c:v`, `-c:a`, `-crf` or `-b:v`).
4. Output filename/extension is generated automatically.

### Technical Approach

```ts
const container = 'mp4';
const videoCodec = 'libx264';
const audioCodec = 'aac';
const flags = ['-c:v', videoCodec, '-c:a', audioCodec, '-crf', '22'];
```

### Key Considerations
- Surface incompatible codec/container pairs with warnings.
- Allow “copy” passthrough for lossless streams (`-c copy`).
- Provide sensible defaults by input format.

## Acceptance Criteria

- [x] Users can select container and codecs. Completed in the convert action editor.
- [x] Command preview reflects all chosen options. Completed via main-process command generation.
- [x] Output file extension matches the chosen container. Completed through output path resolution in the command builder.
