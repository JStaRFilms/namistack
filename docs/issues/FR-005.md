# [FR-005] FFmpeg Flags Explorer With Toggles

## Labels
`MUS`, `enhancement`, `flags`

## User Story
As a user, I want every FFmpeg flag exposed as a simple toggle (and value input when needed), so that I can customize commands without memorizing syntax.

## Proposed Solution

### Overview
Parse `ffmpeg -h` / `ffmpeg -h full` output to generate a searchable list of flags, each with a toggle and optional value input. Selected flags are appended to the command builder.

### Implementation Flow
1. On startup, main process runs `ffmpeg -h full` and caches output.
2. Parser extracts flags, whether they require a value, and short descriptions.
3. Renderer shows a searchable list with toggle + input fields.
4. Selected flags are appended to command preview in real time.

### Technical Approach

```ts
type FlagDef = { name: string; takesValue: boolean; description: string };
const flags = parseFfmpegHelp(stdout);
```

### Key Considerations
- Support flags that repeat or are context-specific (e.g., `-vf`, `-af`).
- Provide guardrails for mutually exclusive flags.
- Allow raw custom flags as an escape hatch.

## Acceptance Criteria

- [x] Flags list is searchable and grouped by category. Completed via parsed FFmpeg flag definitions and renderer search.
- [x] Toggling a flag updates the command preview. Completed via live preview regeneration.
- [x] Flags requiring values show input fields and validate entries. Completed via per-flag value inputs in the advanced flags panel.
