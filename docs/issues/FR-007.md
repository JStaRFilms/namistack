# [FR-007] Presets and History

## Labels
`Future`, `enhancement`, `presets`

## User Story
As a user, I want to save presets and view past jobs, so that I can repeat workflows quickly.

## Proposed Solution

### Overview
Allow users to save current action settings as presets and store a history of executed jobs with outputs.

### Implementation Flow
1. User saves a preset with a name and description.
2. Presets are stored locally (JSON) and loaded at startup.
3. Job history is appended after each run.
4. User can re-run a preset or history item.

### Technical Approach

```ts
const presetsPath = path.join(app.getPath('userData'), 'presets.json');
```

### Key Considerations
- Version presets to handle schema changes.
- Provide import/export for sharing.
- Support tagging or folders for organization.

## Acceptance Criteria

- [ ] Users can save and reapply presets.
- [ ] A history list shows past commands and outputs.
- [ ] Presets and history persist across sessions.
