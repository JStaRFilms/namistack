# [FR-004] Lossless Merge (Concat)

## Labels
`MUS`, `enhancement`, `actions`

## User Story
As a user, I want to merge multiple clips into one lossless video, so that I can combine footage without re-encoding.

## Proposed Solution

### Overview
Implement a merge action using the concat demuxer with a generated list file, validating that inputs are compatible.

### Implementation Flow
1. User selects multiple clips and chooses “Merge Lossless.”
2. App validates codec, resolution, and frame rate compatibility.
3. App writes a temporary concat list file and runs `ffmpeg -f concat -safe 0 -i list.txt -c copy output`.
4. Output file is saved in the chosen directory.

const listFile = files.map(f => `file '${f.replace(/'/g, "'\\''")}'`).join('\n');

### Key Considerations
- Show a clear incompatibility report if inputs differ.
- Allow an optional “re-encode to match” fallback (future).
- Use safe temp paths and clean up after completion.

## Acceptance Criteria

- [x] Multiple clips can be selected and merged losslessly. Completed via concat demuxer workflow and multi-file selection.
- [x] Incompatible clips are detected and explained. Completed via merge warnings for mixed codecs and resolutions.
- [x] Output plays back as a single continuous video without re-encoding. Completed via `-c copy` merge execution.
