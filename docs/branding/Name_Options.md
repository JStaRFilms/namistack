# Name Options

## Shortlist

| Name | Base Word | Origin | Meaning | Case For It | Suggested Handles |
|---|---|---|---|---|---|
| NamiStack | Nami | Japanese | Wave | Feels smooth, minimal, and still technical. The `Stack` suffix keeps it grounded for a serious desktop workflow tool. | `namistack.dev`, `namistack.app`, `getnamistack.com` |
| HikoFlow | Hiko | Maori | Flash / electricity | Suggests speed and visual energy. Softer and more creator-friendly, but a little lighter for a serious media utility. | `hikoflow.app`, `hikoflow.dev`, `usehikoflow.com` |
| FaberCore | Faber | Latin | Maker / builder | Strong, professional, and tool-like. It leans more infrastructure than creative software, which is good for pros but less distinctive visually. | `fabercore.dev`, `fabercore.app`, `fabercorehq.com` |
| SareForge | Sare | Yoruba | Run / speed | Great semantic fit for transcoding and batch jobs. Distinctive and energetic, though it may need one extra beat of explanation on first introduction. | `sareforge.dev`, `sareforge.app`, `getsareforge.com` |
| MauriKit | Mauri | Maori | Essence / life force | Beautiful sound and warm creative tone. Best if the product leans more creator-branded than utility-branded. | `maurikit.app`, `maurikit.dev`, `usemaurikit.com` |

## Recommendation

### NamiStack

**Why this is the lead pick**
- The wave meaning fits media motion, timelines, and file handling without sounding too flashy.
- `Stack` keeps it productized and technical without forcing heavy maker language.
- It works for both current scope and future growth: presets, batch pipelines, packaging, and creator workflows.
- It is short enough to say once and remember.

## Working Brand Decision

This project will use **NamiStack** as the product name for branding, packaging, and publishing unless changed before repo creation.
